Echo Of Panshan

This project innovates a gamified assisted driving training experience being developed with Unreal Engine 5, it fully integrates into both development and existing BMW system for hardware and software. Showcased in a real car mock-up, it features responsive interactions to driving inputs including braking and accelerator pedal, hands-on detection and steering wheel buttons. The experience includes an ADAS tutorial that builds user confidence and knowledge, while a 3D visualized, gamified demo provides an engaging and immersive educational experience.

VISION

A Gamified Tutorial

The project’s technical validation hinges on four key points: development entirely with Unreal Engine for seamless hardware and software integration; a real car mock-up using Unreal Engine for interactive showroom experiences; an ADAS tutorial to build user knowledge and confidence; and a 3D gamified demo that enhances learning with an immersive, enjoyable simulation.

USER RESEARCH

"Why You Never Used ADAS Functions?"

"In Which Case Would You Like To Use ADAS?"

We identified pain points in ADAS learning through a focus group with experienced drivers hesitant to use ADAS. Participants cited a lack of confidence and safety concerns, especially at high speeds, and were overwhelmed by the complexity of ADAS features. These insights shaped our strategy to develop a gamified tutorial that builds trust and eases anxiety pre-learning. By offering an engaging, interactive practice rather than traditional slides, users learn ADAS basics through fun, level-by-level challenges, gradually gaining confidence.

USER JOURNEY

We conducted an in-depth analysis of numerous Chinese and global vehicles, Our design strategy centers on learning through practice. We've structured the user journey by dividing Assisted Driving Mode (ADM) tasks into levels. Users start with a foundational ADM overview and then advance through essential BMW training modules, completing successive missions.

INFO ARCHITECTURE

The product's main interface is a 3D game view in Unreal Engine, featuring a seamless driving experience with a simulated environment, key traffic objects, and the ego car. It includes a combined speedometer and ADAS icon, along with an ADAS status indicator. A tutorial video guides user actions, and voice guidance offers explanations and support throughout the experience.

MOCK-UP

LEVEL 0 : Starter Plaza

In the first training level, users learn to activate Assisted Driving Mode (ADM) from manual driving. Upon hands-on detection, a countdown prompts pedal use. When reaching higher speeds, the level triggers, followed by a celebratory notification and smooth transition.

LEVEL 1 : Activate Assisted Driving Mode

Users can effortlessly transition to the next level by clicking a button, where they will learn to activate Assisted Driving Mode (ADM) while driving at high speeds. Guided by voice instructions and a tutorial video, users will encounter animations detailing ADM operations, including Adaptive Cruise Control and Lane Keeping Assistance.

LEVEL 2: Speed Control

Subsequent levels follow a similar structure: users are guided by voice and a demo video, interacting with the MFL to receive feedback on the 3D game view. Once familiar with activating ADM, users can tackle more challenging tasks, learning to use the "set" and "minus/plus" buttons to control speed.

LEVEL 3: Deactivate and Resume
